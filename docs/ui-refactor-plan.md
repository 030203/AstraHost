# UI 重构计划

## 1. 现状审视

### 1.1 当前技术栈
- 前端框架：Vue 3 + Vue Router + Pinia
- UI 组件库：Element Plus
- 构建工具：Vite

### 1.2 当前 UI 主要问题
- `frontend/src/App.vue` 同时承载了导航、布局、主题和状态同步，壳层职责偏重。
- 首页 `frontend/src/views/Home.vue` 已有视觉尝试，但业务数据、布局结构、配色和样式都堆在单文件里，复用性弱。
- 登录页 / 注册页、预订页、统计页、详情页之间的设计语言不统一，暖色目标和当前冷蓝主色冲突明显。
- 页面缺少统一的设计 token，阴影、圆角、间距、边框、交互状态在不同页面里不一致。
- 部分可点击区域依赖卡片整体点击或局部视觉暗示，A11y 和触控友好度可以继续加强。
- 已有加载态主要依赖 Element 默认骨架，缺少统一骨架样式与轻量过渡。

## 2. 本次重构目标

### 2.1 体验目标
- 将全站主色调统一为“暖色 + 牛奶色”体系，减少冷蓝带来的演示感，提升民宿场景的亲和力。
- 强化首页第一屏的信息优先级，让访客、用户、商户都能快速找到下一步。
- 保持后台管理类页面的效率感，避免过度营销化。
- 增加平滑过渡、悬停反馈、加载骨架和内容分区，让页面更现代也更稳定。

### 2.2 工程目标
- 提取全局主题变量与 Element Plus 覆盖层，减少重复样式。
- 提取会话同步、图片解析、公共头部/卡片/鉴权展示等通用能力。
- 将首页、登录/注册页、快速预订页、统计页、详情页拆成更清晰的结构。

## 3. 设计方向

### 3.1 推荐色板
- 主背景 `#fff8f1`：牛奶白，作为页面大底。
- 浅表面 `#fffdf9`：卡片/浮层基底。
- 主品牌色 `#c9866a`：暖陶土色，承担主按钮、强调态。
- 深品牌色 `#a85f47`：主按钮 hover / active。
- 辅助金色 `#d8a46f`：标签、重点数字、轻强调。
- 鼠尾草绿 `#8ba48f`：状态补色，平衡暖色调。
- 正文主色 `#3f312c`：暖灰棕，替代纯黑。
- 次级文字 `#7d6d66`：说明文本。
- 柔和边框 `rgba(128, 93, 72, 0.12)`。

### 3.2 视觉关键词
- 温暖、克制、安静、细腻。
- 卡片不厚重，强调层次而不是大面积重阴影。
- 首页加入一张暖色场景插画/位图，避免只有文字和卡片。

## 4. 组件化拆分计划

### 4.1 全局层
- 新增全局主题文件：
  - `frontend/src/styles/theme.css`
- 新增会话同步 composable：
  - `frontend/src/composables/useSession.js`
- 新增媒体/图片工具：
  - `frontend/src/utils/media.js`

### 4.2 公共组件
- `frontend/src/components/shared/PageIntro.vue`
  - 统一页面标题、说明、角标与右侧操作区。
- `frontend/src/components/shared/AppStatCard.vue`
  - 统一指标卡样式，支持说明与骨架态。
- `frontend/src/components/auth/AuthShowcase.vue`
  - 复用登录/注册左侧暖色展示区。

### 4.3 首页组件
- `frontend/src/components/home/HomeHeroScene.vue`
  - 负责首页插画、浮层信息卡与暖色视觉展示。

## 5. 页面重构清单

### 5.1 App 壳层
- 重构导航结构，用配置驱动菜单项。
- 调整顶部导航为暖色半透明风格，移动端改为更稳定的抽屉式下拉布局。
- 统一主内容容器、圆角、留白、阴影和页面切换动画。

### 5.2 首页
- 重构为四层结构：
  1. Hero 首屏：品牌价值、主操作、实时摘要、插画场景。
  2. 快速入口：预订、订单、统计、设置。
  3. 推荐房源：真实图片卡片，承接用户下一步浏览。
  4. 体验亮点：移动端稳定性、运营效率、AI 辅助等。
- 首页数据从真实 API 获取，失败时保留可读兜底。
- 首页骨架态和卡片 hover 动效统一。

### 5.3 登录 / 注册
- 合并视觉语言，抽取共享展示组件。
- 表单区域使用更轻的边框、层次和状态提示。
- 示例账号、角色说明、商户信息分组重新排版。

### 5.4 快速预订
- 左侧房源浏览卡片更像真实“可选项”，强化图片、价格、位置和操作按钮。
- 右侧表单做成固定工作面板风格，字段层级更清楚。
- 增加空态、骨架态、筛选框视觉一致性。

### 5.5 数据统计
- 替换为更现代的运营看板布局。
- 增加摘要指标、状态分布区、运营说明文本。
- 使用暖色状态条和骨架态。

### 5.6 民宿详情
- 详情头图、核心信息、预订入口和政策区重新分层。
- 房型卡片统一图片比例、价格样式和按钮位置。
- 对移动端做纵向栈式布局，减少横向挤压。

### 5.7 404 / 辅助状态组件
- 统一暖色空态、错误态、加载态。
- 调整浮动 AI 助手的色调，使其不与新主题冲突。

## 6. 动效与无障碍

### 6.1 动效
- 页面切换：轻微位移 + 淡入淡出。
- 卡片 hover：上浮 2px 到 4px，阴影轻微增强。
- 按钮 hover / active：亮度与投影细微变化。
- 骨架屏：统一明暗流动，不使用突兀闪烁。

### 6.2 A11y
- 交互元素保留明确的 `button` / `a` 语义。
- 焦点态统一使用可见 outline。
- 图片增加 `alt` 或用语义容器承载纯装饰背景。
- 色彩对比保持正文可读，不用过淡浅灰承载关键信息。

## 7. 验收清单
- 首页、登录、注册、快速预订、统计、详情页视觉风格统一。
- 移动端 390px 左右宽度下无文字溢出、卡片错位、按钮挤压。
- 导航、主要按钮、筛选、卡片 hover、加载态行为正常。
- `npm run build` 通过。
- 本地预览启动并使用浏览器完成首页、登录、预订页的可视检查。

## 8. 执行顺序
1. 建立主题层和公共工具。
2. 重构 App 壳层与全局状态同步。
3. 重构首页与首页插画区。
4. 重构登录 / 注册共享结构。
5. 重构快速预订、统计、详情页。
6. 统一空态 / 错误态 / AI 助手色调。
7. 构建、启动预览、浏览器验收并修正细节。
