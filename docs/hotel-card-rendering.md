# 酒店推荐卡片渲染系统

## 概述

当 AI 返回酒店推荐内容时，不直接渲染 Markdown 文本，而是解析内容并渲染为精美的卡片组件。

## 功能特性

### 1. 智能解析
- 自动检测 AI 响应中的酒店推荐内容
- 支持多种文本格式和标记方式
- 提取分类（新开业、口岸首选、高端奢华等）
- 解析酒店名称、位置、亮点、设施、价格、评分

### 2. 卡片组件结构

每张酒店卡片包含：

**顶部图片区**（110px 高度）
- 灰色占位背景 + 建筑图标
- 左上角分类角标（不同颜色区分）

**卡片主体**
- 酒店名称（font-weight: 500）
- 位置（小字 + 地图图标）
- 一句话亮点描述
- 设施标签列表（胶囊样式）

**卡片底部**
- 左侧：价格（橙红色 #993C1D）
- 右侧：评分（绿色角标 #085041）

### 3. 布局规则

- **横向排列**：同一分类的酒店使用 CSS Grid auto-fit，最小列宽 190px
- **分类分隔**：不同分类之间用标签行 + 细线（0.5px）分隔
- **响应式**：移动端自动调整为单列布局
- **垂直滚动**：整体无需分页

### 4. 样式规范

**配色方案**
- 主色调：橙红 #993C1D（价格）、绿色 #085041（评分）
- 卡片：白底 + 0.5px 边框 + border-radius 12px
- 角标配色按分类区分：
  - 新开业 = 绿色渐变 (#10b981 → #059669)
  - 口岸 = 蓝色渐变 (#3b82f6 → #2563eb)
  - 奢华 = 金色渐变 (#f59e0b → #d97706)
  - 商务 = 靛蓝渐变 (#6366f1 → #4f46e5)
  - 亲子 = 粉色渐变 (#ec4899 → #db2777)
  - 度假 = 紫色渐变 (#8b5cf6 → #7c3aed)

**设计原则**
- ✅ 简洁扁平，无渐变背景
- ✅ 无阴影、无模糊效果
- ✅ 0.5px 细边框
- ✅ 圆角 12px

## 核心文件说明

### HotelCardGrid.vue
卡片网格渲染组件，接收解析后的数据结构：

```javascript
{
  categories: [
    {
      name: '新开业',
      hotels: [
        {
          name: '深圳湾万怡酒店',
          location: '南山区深圳湾',
          highlight: '2024年全新开业，现代设计与智能科技完美融合',
          facilities: ['免费WiFi', '健身房', '游泳池'],
          price: '¥680起',
          rating: '9.2'
        }
      ]
    }
  ]
}
```

### hotelParser.js
智能解析器，主要函数：

**`containsHotelRecommendation(text)`**
- 检测文本是否包含酒店推荐内容
- 返回：`boolean`

**`parseHotelRecommendations(text)`**
- 解析 AI 文本，提取酒店信息
- 返回：`Array<Category>` 或 `null`

**支持的文本格式**
```
【新开业】

1. 深圳湾万怡酒店
位于：南山区深圳湾
亮点：2024年全新开业，现代设计与智能科技完美融合
设施：免费WiFi、健身房、游泳池、停车场
价格：¥680起
评分：9.2分

2. 前海希尔顿花园酒店
...
```

### AiAssistant.vue 集成

在消息渲染层自动检测并渲染卡片：

```vue
<HotelCardGrid
  v-if="item.role === 'assistant' && item.hotelCards"
  :categories="item.hotelCards"
/>
<p v-else>{{ item.content }}</p>
```

解析逻辑：
```javascript
const hotelCards = parseHotelRecommendations(finalAnswer)

messages.value.push({
  id: `assistant-${Date.now()}`,
  role: 'assistant',
  content: finalAnswer,
  hotelCards: hotelCards  // 解析结果
})
```

## 解析器能力

### 支持的提取内容

✅ **酒店名称**
- 自动去除序号（1. 2. 3.）
- 去除 Markdown 加粗标记（**）
- 去除中文方括号【】

✅ **位置信息**
- 关键词：`位于`、`地址`、`坐标`、`靠近`
- 自动识别包含区、路、街、镇、村、口岸的文本

✅ **亮点描述**
- 关键词：`亮点`、`特色`、`推荐理由`
- 自动提取 15-120 字符的描述性文本

✅ **设施标签**
- 预定义 20+ 常见设施关键词
- 自动提取并限制显示 5 个

✅ **价格**
- 识别：`¥`、`￥`、`元`、`起`
- 格式：`¥680起`

✅ **评分**
- 识别：`评分`、`评价`、`得分`
- 提取：`9.2分` → `9.2`

### 支持的文本格式

1. **带标题分类**
```
【新开业】
1. 酒店名称
...

【口岸首选】
1. 酒店名称
...
```

2. **Markdown 标题**
```
## 新开业

1. 酒店名称
...

## 口岸首选
```

3. **无分类**
```
1. 深圳湾万怡酒店
位于：南山区深圳湾
...

2. 前海希尔顿花园酒店
...
```

## 性能优化

1. **按需渲染**：只有检测到酒店推荐时才解析和渲染卡片
2. **轻量组件**：无第三方依赖，纯 Vue 3 组合式 API
3. **CSS Grid**：利用浏览器原生能力实现响应式布局
4. **最小重绘**：使用 `:key` 优化列表渲染

## 故障排查

### 卡片不显示
1. 检查 AI 响应是否包含酒店关键词
2. 打开浏览器控制台，查看 `parseHotelRecommendations()` 返回值
3. 验证文本格式是否符合解析规则

### 解析不完整
1. 检查 AI 文本是否有特殊字符或格式
2. 调整 `hotelParser.js` 中的正则表达式
3. 在测试页面的解析器测试中调试

### 样式问题
1. 检查浏览器是否支持 CSS Grid
2. 验证父容器宽度是否足够
3. 检查是否有全局 CSS 冲突
