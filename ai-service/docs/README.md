# ai-service 开发文档索引

本目录保存客服 Agent 项目开发相关的需求、技术、设计和执行标准。

## 文档列表

| 文件 | 说明 |
| --- | --- |
| `development-requirements.md` | 开发需求、范围和优先级 |
| `technical-standards.md` | 技术规范、模块边界、接口和测试要求 |
| `design-standards.md` | Agent 设计规范、客服体验和安全行为标准 |
| `execution-steps.md` | 分阶段开发步骤、验收标准和日志要求 |
| `customer-service-agent-optimization-plan.md` | 当前客服 Agent 的详细优化方案 |
| `detailed-task-checklist.md` | 基于当前真实代码状态整理的详细任务清单和执行顺序 |

## 使用方式

- 开发前先读 `AGENTS.md` 和本索引。
- 做需求拆分时读 `development-requirements.md`。
- 写代码前读 `technical-standards.md`。
- 调整 Agent 行为、prompt、工具策略前读 `design-standards.md`。
- 排期和落地时读 `execution-steps.md`。
- 每天开发事项记录到 `dev-logs/YYYY-MM-DD.md`。
